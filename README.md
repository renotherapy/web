# Renotherapy Construction website

A responsive, SEO-ready static website built with semantic HTML, a small amount of vanilla JavaScript, and compiled Tailwind CSS.

## Commands

- `npm run build` — compile Tailwind, optimize images to WebP, and produce `dist/`.
- `npm run check` — validate HTML plus critical SEO and output requirements.
- `npm run dev` — serve the built site at `http://127.0.0.1:4173`.

The published static output is declared in `.openai/hosting.json`.
